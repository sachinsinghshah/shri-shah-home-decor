# Shri Shah Home Decor — Website

Production-grade website for **Shri Shah Home Decor**, Ramnagar, Nainital, Uttarakhand.

- **URL:** https://shahhomedecor.in (after deployment)
- **Phone:** 9548506887
- **Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, shadcn/ui, GSAP 3 + Motion

---

## Quick Start

```bash
npm run dev        # Start dev server → http://localhost:3000
npm run build      # Production build + auto-generates sitemap.xml & robots.txt
npm run start      # Serve production build locally
npm run lint       # Run ESLint
```

## Content Customisation Guide

| What to change | File to edit |
|----------------|-------------|
| Phone, address, hours | `src/lib/constants.ts` → `SITE` object |
| Service names & descriptions | `src/lib/constants.ts` → `SERVICES` array |
| Gallery photos | `src/lib/constants.ts` → `GALLERY_ITEMS` + add files to `public/images/gallery/` |
| Testimonials | `src/lib/constants.ts` → `TESTIMONIALS` array |
| Brand colours | `src/app/globals.css` → `@theme` block |
| Logo | Replace `public/logo.png` (transparent background recommended) |
| OG share image | Replace `public/og-image.jpg` (must be exactly 1200×630 px) |
| Google Maps embed | `src/lib/constants.ts` → `SITE.mapEmbed` |

## Adding Real Photos

1. Name descriptively: `pvc-living-room-1.jpg`, `3d-wallpaper-bedroom.jpg`
2. Place in `public/images/gallery/`
3. Update `GALLERY_ITEMS` in `src/lib/constants.ts` with real `src` paths
4. Rebuild: `npm run build`

## Deployment to Vercel

1. **Push to GitHub:**
   ```bash
   git add . && git commit -m "Initial website" && git push
   ```

2. **Import to Vercel:**
   - Go to https://vercel.com/new → Import your GitHub repo
   - Framework: **Next.js** (auto-detected) → Deploy

3. **Add custom domain:**
   - Vercel Dashboard → Your Project → Settings → Domains
   - Add `shahhomedecor.in` and set DNS records as instructed

4. **Environment variables (Vercel dashboard):**
   ```
   GOOGLE_SITE_VERIFICATION = your_google_search_console_token
   ```

5. **After deploy — submit sitemap:**
   - Google Search Console: https://search.google.com/search-console
     - Add property `https://shahhomedecor.in`
     - Sitemaps → Submit: `https://shahhomedecor.in/sitemap.xml`
   - Bing Webmaster: https://www.bing.com/webmasters
